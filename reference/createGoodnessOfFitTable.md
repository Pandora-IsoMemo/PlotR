# Create Goodness Of Fit Table

Create Goodness Of Fit Table

## Usage

``` r
createGoodnessOfFitTable(x, llog, edf)
```

## Arguments

- x:

  (character) name of the model

- llog:

  (matrix) llog matrix of a model output

- edf:

  (numeric) effective degrees of freedom, i.e.: sum of the row variances
  of the llog matrix
