# Add a legend to an existing plot

Add a legend to an existing plot

## Usage

``` r
addLegendServer(id, position, title, legendEntries, fillColor)
```

## Arguments

- id:

  module id

- position:

  legend position, e.g. "bottomright", "bottom", "bottomleft", "left",
  "topleft", "top", "topright", "right" and "center"

- title:

  legend title

- legendEntries:

  names of legend entries

- fillColor:

  color for the legend symbols
