# Derive Explanatory from Densities of the Estimation Sample

Derive Explanatory from Densities of the Estimation Sample

## Usage

``` r
deriveSingleExplanatory(yMean, xVar, predDensities, quantile = 0.95)
```

## Arguments

- yMean:

  numeric value for which to derive the explanatory

- xVar:

  numeric vector of possible values for the explanatory

- predDensities:

  list of outputs from density()

- quantile:

  (numeric) value between (0,1)
