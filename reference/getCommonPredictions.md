# Predictions for Selected Models for a Common X Range

Predictions for Selected Models for a Common X Range

## Usage

``` r
getCommonPredictions(activeDataList, xRange, isTest = FALSE)
```

## Arguments

- activeDataList:

  (reactive) list of selected saved data

- xRange:

  (numeric) range for which correlation will be calculated

- isTest:

  TRUE if used within tests
