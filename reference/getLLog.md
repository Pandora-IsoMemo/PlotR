# Get LLog

Log likelihood computation for (W)AIC

## Usage

``` r
getLLog(matrixDiff, XX, betamcSigma, smcSmpls, sdVar)
```

## Arguments

- matrixDiff:

  (matrix) matrix difference

- XX:

  (matrix) design matrix

- betamcSigma:

  (matrix) coefficients of varying standard deviation spline

- smcSmpls:

  (numeric) sigmas of MC samples

- sdVar:

  (logical) TRUE if variable standard deviation
