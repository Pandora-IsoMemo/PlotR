# Select Data Wrapper

Select Data Wrapper

## Usage

``` r
selectDataWrapper(plotValues, activeFile, activeFileData, dataSelection)
```

## Arguments

- plotValues:

  (list) list with all values required for the plot

- activeFile:

  (character) name of the selected file

- activeFileData:

  (data.frame) content of the selected file

- dataSelection:

  (list) list of reactive selected columns of the current file
