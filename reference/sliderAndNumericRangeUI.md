# Slider And Input UI

UI of the Slider And Input module

## Usage

``` r
sliderAndNumericRangeUI(id, label, min, max, value, dragRange)
```

## Arguments

- id:

  id of module

- label:

  label

- min:

  (numeric) minumum

- max:

  (numeric) maximum

- value:

  (numeric) default value

- dragRange:

  (logical) dragRange
