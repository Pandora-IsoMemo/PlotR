# Predict Estimations for More X Input

Predict Estimations for More X Input

## Usage

``` r
predictAdditionalData(moreMean, moreSD, plotValues, moreNSample = NULL)
```

## Arguments

- moreMean:

  numeric mean input value

- moreSD:

  numeric sd for input value

- plotValues:

  list of plotValues from a savedPlots element

- moreNSample:

  (numeric) number of samples for the input
